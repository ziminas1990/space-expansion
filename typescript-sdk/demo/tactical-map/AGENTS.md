# Tactical map

## Images design

All images should be in stylized semi-realistic 2D game art, top-down view,
with a clean readable shapes and medium detail:

- thin dark colored outlines
- simplified cel-like shading
- controlled soft gradients
- restrained color palette
- subtle painted texture
- strong silhouette
- no photorealism
- no complex lighting
- no excessive microdetails

Objects should use predominantly light or medium-light colors so they remain
clearly visible against the dark space background, as the asteroid does. Reserve
dark colors for thin outlines, craters, recesses, and limited shadows; keep the
main visible surfaces light.
