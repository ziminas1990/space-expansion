# Игра

Модуль **Game** висит на корневом коммутаторе каждого игрока. Это не корабль: его нельзя построить или заспаунить. Через него игрок следит за матчем — в том числе получает итог, когда игра заканчивается.

Тип модуля в списке слотов коммутатора — `"Game"`.

## Интерфейс IGame

```protobuf
message IGame {

  message Score {
    string player = 1;
    uint32 score  = 2;
  }

  message GameOver {
    repeated Score leaders = 1;
  }

  oneof choice {
    bool     monitor          = 1;

    GameOver game_over_report = 21;
  }
}
```

## Как следить за матчем?

Нужно открыть отдельную сессию (туннель) к слоту Game и отправить **monitor**. Значение поля игнорируется.

После подписки сервер присылает обновления матча на эту же сессию. Сейчас единственное такое обновление — **game_over_report**, когда матч завершён. Если игра уже закончилась к моменту подписки, сервер отправит сохранённый итог сразу.

Несколько сессий могут одновременно следить за одной и той же игрой. Закрытие сессии снимает только её подписку; остальные мониторы продолжают получать обновления.

## Итог матча

**game_over_report** имеет тип **GameOver**:

```protobuf
message GameOver {
  repeated Score leaders = 1;
}

message Score {
  string player = 1;
  uint32 score  = 2;
}
```

**leaders** — таблица результатов, отсортированная по убыванию очков: первый элемент — победитель. **player** — логин, **score** — набранные очки.
