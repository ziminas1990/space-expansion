# SES-216: TypeScript tactical map client

## Background

The TypeScript SDK has a headless harvester, but no way for a player to
see the world. Ships and asteroids exist only as objects in a control
loop. There is no map to look at, no list of ships to pick from, and no
camera to follow a ship across the field.

A browser map is the missing counterpart: the same TypeScript SDK, used
to watch the player's world instead of driving it.

This is a new application. Do not port or copy an existing browser
client.

## Require

Add a tactical map client at `typescript-sdk/demo/tactical-map/`.

It is one TypeScript/Node application. One command starts it:
`npm run tactical-map`. That command serves the page, accepts the
browser connection, handles login, and talks to the game server through
the TypeScript SDK.

Inside the demo, keep two directories:

- `backend` — the page, login, the live connection to the browser, and
  the SDK session to the game server;
- `frontend` — everything the browser uses to draw the world and the
  ship list.

Write `SPEC.md` in that directory as part of the work. It describes
what a player sees and does, not how the client is built. It does not
name a frontend library.

The client must:

- fill the browser window with a map of the player's ships and
  asteroids;
- show a window over the map that lists those ships;
- center the camera on a ship and follow it when the player selects
  that ship;
- drop the follow on Escape, leaving the camera where it was;
- scale the scene with the mouse wheel when the pointer is over the
  map, around the point under the cursor.

## Acceptance

- `npm run tactical-map` from the TypeScript SDK starts the application
  as a single process.
- After login, a browser at the served page shows a live map of the
  player's ships and asteroids, filling the window, with a ship list
  over the map.
- Choosing a ship from that list centers the camera on it and keeps the
  camera following as the ship moves.
- Escape drops that follow. The camera stays where it was at that
  moment and no longer tracks the ship.
- With the pointer over the map, the mouse wheel scales the scene
  around the point under the cursor.
- The demo directory contains a `SPEC.md` that describes this behavior
  and matches what the running client does.
