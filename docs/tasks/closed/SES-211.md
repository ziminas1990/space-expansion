# SES-211: TypeScript headless harvester client

## Background

SES-210 introduces a headless harvester client in the Python SDK
(`python-sdk/demo/harvester/`). The TypeScript SDK has its own highlevel
layer (`typescript-sdk/highlevel/`) with objects for ships, engines,
asteroid miners, shipyards, resource containers, and more, but no
end-to-end demo that exercises them together.

## Require

Add a headless harvester client at `typescript-sdk/demo/harvester/` that is
functionally identical to the Python client from SES-210:

- automatic resource mining loop,
- automatic ship-building loop,
- commutator monitoring that attaches newly spawned ships to the mining loop,
- credentials via config file or command-line arguments,
- clean exit on SIGINT / SIGTERM.

The implementation must use highlevel objects from `typescript-sdk/highlevel/`
wherever they exist. Direct use of lowlevel or midlevel APIs is only
acceptable where no highlevel equivalent is available.

## Acceptance

- `typescript-sdk/demo/harvester/` can be launched from the command line
  without a display server.
- After launch the client mines asteroids and builds new ships automatically,
  matching the behaviour of the Python harvester from SES-210.
- The implementation does not bypass highlevel objects when a suitable
  highlevel API exists.
