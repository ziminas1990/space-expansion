# SES-227: Add ship orientation and a rotate command

## Background

A ship reports where it is and how fast it is moving. It does not report
which way it is facing, and the player has no command to turn it.

The main engine will push only along the nose. A facing and a turn have to
exist on the ship before that engine can be aimed. This is the first step
of [EPIC-1](../epics/EPIC-1/README.md).

## Require

Extend the ship so it has a facing and can be ordered to turn.

- The ship state includes the orientation. Orientation is a vector in
  global coordinates, from the ship's center toward its nose. It is a
  direction.
- The ship specification includes the maximum rotation speed, in radians
  per second. The value is set on the ship blueprint, and the blueprint
  properties of a ship publish it.
- A rotate command takes a target direction and a desired rotation speed.
  The ship turns at that speed along the shorter arc until the nose matches
  the target. The speed used does not exceed the maximum. When the two arcs
  are the same length, the ship always turns the same way.
- The server answers the command at once with an acknowledgement, then
  sends nothing further about that turn. The turn runs to completion on
  the server.
- A rotate command that arrives during a turn replaces that turn.

The ship protocol documentation describes the orientation, the maximum
rotation speed, and the rotate command.

## Acceptance

- A ship state includes the nose direction. A state read while the ship is
  turning returns the direction at that moment.
- The ship specification reports the maximum rotation speed in radians per
  second. The number is the one set on that ship's blueprint. Two ships
  with different blueprint values report different speeds.
- The published blueprint of a ship includes that same maximum rotation
  speed.
- After a rotate command, the nose reaches the target direction. The turn
  takes the shorter arc and lasts for that angle divided by the speed
  used. A requested speed above the maximum is carried out at the maximum.
- The only reply to the command is an immediate acknowledgement. The server
  does not send a separate message when the turn finishes.
- A second rotate command during a turn leaves the first target and turns
  toward the new one.
- The ship protocol documentation describes the orientation, the maximum
  rotation speed, and the rotate command.
