# SES-229: Add the IHoverEngine interface

## Background

IRCS can push a ship in any direction. The main engine should not. It
pushes along the nose, so the player aims it by turning the ship.

The ship can already be ordered onto a facing. Nothing on board yet turns
that facing into thrust. This is the third step of
[EPIC-1](../epics/EPIC-1/README.md).

## Require

Add an IHoverEngine interface, the ship's main engine. The module type is
HoverEngine.

- The specification reports the maximum thrust. It does not describe a
  way to aim the engine.
- The command sets the thrust magnitude. It does not take a direction.
  The thrust stays at that value until a later command sets another one,
  including zero.
- The force is applied along the ship's current orientation. If the ship
  turns while the engine is producing thrust, the force turns with the
  nose.
- The magnitude does not exceed the maximum.

The client can read the thrust that is applied. The protocol documentation
describes IHoverEngine as the main engine, the maximum thrust, and the
command.

## Acceptance

- A ship can carry a HoverEngine module, and a client can open it and read
  a specification whose limit is the maximum thrust.
- Setting a thrust accelerates the ship along its nose. The acceleration
  matches that thrust and the ship's mass, and it does not exceed the
  maximum thrust.
- Turning the ship while the engine is producing thrust changes the
  direction of the acceleration with the nose. The magnitude stays the one
  that was set.
- Setting the thrust to zero stops that acceleration.
- The client can read back the thrust that is applied.
- The protocol documentation describes IHoverEngine as the main engine
  that thrusts only along the ship's orientation.
