# SES-214: Planner targets always have time and velocity

## Background

A target for a burn is a pose in the world: where something is, how it is
moving, and *when* that was true. Time and velocity are not optional
decorations. Without a time, the sample has no age and the planner cannot
tell a current pose from a stale one. Without a velocity, it cannot tell
“stop here” from “match this motion”.

Today a caller can still omit the time and get a second planning path that
treats the pose as “now”. That looks like a convenience. It is an ambiguous
target. Stopping at a point is already expressible: zero velocity at a
known time. Intercepting a body is the same shape with a non-zero velocity
and the time of the sample.

## Require

Make the planning contract require a target that always includes both a
time and a velocity. There is no timeless target and no velocity-less
target.

How that contract is enforced is left open.

## Acceptance

- Every plan is built from a target that has both a time and a velocity.
- “Stop at this point” is a target with zero velocity at a known time, not
  a missing velocity or a missing time.
- There is no planning path that treats an absent time as “use this pose
  as now”.
