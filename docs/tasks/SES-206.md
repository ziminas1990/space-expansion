# SES-206: Cover the TypeScript SDK with functional tests against a live server

## Goal

Add a TypeScript functional test suite that exercises the SDK against a real
server: login, blueprints, administrator clock/spawn/manipulator, resource
container, messanger, system clock, passive scanner, asteroid miner, shipyard,
and commutator/navigation/messanger E2E.

## Constraints

- Tests use the midlevel API, not highlevel wrappers.
- Sequential run (`npm test` with `SPEX_SERVER_BINARY`); teardown leaves no
  processes or sockets.
- Random stress cases use a seed; retries are not allowed.
